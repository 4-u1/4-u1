## 📌 بيان المشكلة (Problem Statement)

تشهد الوجهات التراثية والسياحية الكبرى حول العالم - وفي مقدمتها **حي الطريف التاريخي بالدرعية المسجل في قائمة التراث العالمي لدى اليونسكو** - تحديات تشغيلية ولوجستية معقدة تتصاعد خلال المواسم والسياحة الكثيفة:

1. **مخاطر التكدس والاختناقات في الأزقة التراثية الضيقة**: طبيعة العمران النجدي التراثي بأسواره وأزقته المحدودة تتطلب توجيهًا استباقياً لحظياً لمنع التدافع والتكدس عند النقاط الحرجة.
2. **صعوبة التنبؤ المبكر بالمخاطر وتدفق الزوار**: الاعتماد على الكاميرات التقليدية والردود الميدانية المتأخرة يؤدي إلى بطء في اتخاذ القرار وتأخير تدخل فرق الاستجابة.
3. **تأمين الممرات الخاصة والمواكب الرسمية دون تعطيل حركة الزوار**: صياغة مسارات آمنة ومغلقة للوفود الرسمية (VIP Delegations) تتطلب توجيهاً ذكياً ومرناً لتدفق الزوار إلى مسارات موازية في ثوانٍ معدودة.
4. **تأثير الظروف المناخية والإجهاد الحراري**: ارتفاع درجات الحرارة يؤثر على سلامة الزوار، مما يفرض وجود نظام ذكي يرصد المناخ الدقيق (Microclimate) ويفعل رذاذ التبريد والإخلاء الطبي فوراً.

## 🇸🇦 الاتساق مع رؤية المملكة 2030 (Vision 2030 Alignment)

تساهم **منصة أورا (AURA)** بشكل مباشر في تحقيق المبادئ الجوهرية لرؤية السعودية 2030:

* 🏛️ **برنامج جودة الحياة (Quality of Life Program)**: تعزيز سلامة ورفاهية زوار وسياح المملكة عبر توفير بيئة سياحية آمنة، ممتعة، ومدعومة بأحدث تقنيات الذكاء الاصطناعي العالمي.
* 🌴 **مبادرة جودة الوجهات التراثية والثقافية (برنامج خدمة ضيوف الرحمن وتطوير التراث)**: الحفاظ على القيمة التاريخية لحي الطريف وتطوير الدرعية كعاصمة للثقافة والتراث العالمي، وتأمين تدفق ملايين الزوار سنوياً.
* 🤖 **الاستراتيجية الوطنية للبيانات والذكاء الاصطناعي (NSDAI)**: توطين تطبيقات التوأم الرقمي (Digital Twin) ومحركات الذكاء الاصطناعي التوليدي من Google لجعل المملكة نموذجاً عالمياً في إدارة المدن والوجهات الذكية.

## 🏛️ المعمارية التقنية للنظام (Technical Architecture)

تم بناء المنصة وفق معمارية موزعة متطورة تدمج بين البث اللحظي للبيانات التليميترية والمحاكاة ثلاثية الأبعاد، مع معالجة سريعة لطلبات الذكاء الاصطناعي:

```
[ Field Sensors / Synthetic Telemetry / CCTV Grid ]
                        │
                        ▼
   [ Natural Language Decision Orchestrator Service ]
                        │
                        ├──────► [ Google Gemini 2.5 Pro / Flash Model Engine ]
                        │               (Risk Prediction & Context Analysis)
                        │
                        ▼
    [ Human-in-the-Loop Operational Command Panel ]
                        │
      ┌─────────────────┼─────────────────┐
      ▼                 ▼                 ▼
[ 3D Digital Twin ]  [ Audio Dispatch ] [ Fleet Control ]
 (VIP Route / Evac)  (Smart PA System) (Shuttles & Golf)
```

### المكونات التقنية الأساسية (Stack Breakdown):
- **الواجهة الأمامية والتصميم (Frontend & Design)**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **الذكاء الاصطناعي المباشر (AI Orchestration)**: Google Gemini 2.5 API (Pro & Flash) للتحليل النصي، صياغة التوصيات، والرد الذكي بأسلوب Human-in-the-Loop.
- **التوأم الرقمي والمحاكاة Visual Digital Twin**: Canvas HTML5 & SVG Vector Rendering لعرض الخرائط اللحظية ومسارات الطوارئ والمواكب.
- **إدارة البيانات والحالة State Management**: React Context, Custom Synthetic Telemetry Engine v2.6 مع مؤشر النبض اللحظي (Heartbeat Health Indicator).

## 🚀 الميزات والأنظمة الميدانية في المنصة (Platform Features)

1. **🚁 درون الاستكشاف الجوي (Drone Thermal Recon)**: مسح ليزري حراري بارتفاع 120 متراً لكشف الكثافات والتجمعات المبكرة.
2. **👑 محاكي ممر موكب الوفود الرسمية (VIP Delegation Corridor)**: تأمين خاطف لمسارات الوفود الرسمية مع توجيه حركة الجمهور مسارياً.
3. **🌤️ مستشعر المناخ والإجهاد الحراري (At-Turaif Microclimate Sensor)**: حساب مؤشر WBGT وتأثير درجة الحرارة والرطوبة وتفعيل التبريد التلقائي.
4. **🎥 شبكة كاميرات المراقبة ومحاكاة قوقل ايرث (AI CCTV & Google Earth 3D)**: بث الكاميرات الميدانية بالذكاء الاصطناعي مع إمكانية استعراض الخريطة الثلاثية الأبعاد.
5. **📢 نظام النداء الصوتي لتوجيه الحشود (AI Audio Dispatch)**: نداءات صوتية موجهة ومصاغة بالذكاء الاصطناعي باللغتين العربية والإنجليزية.
6. **🚑 نظام الإخلاء الطبي والاستجابة للطوارئ (Emergency Evacuation Engine)**: تحديد أسرع ممر آمن لعربات الإسعاف والمستجيبين الأوائل.
7. **🚌 إدارة أسطول عربات الجولف والحافلات (Smart Fleet Dispatch)**: توزيع أسطول النقل الكهربائي بالحي بناءً على كثافات الزوار.
8. **📄 التقرير التنفيذي للجنة التحكيم (Executive Briefing Exporter)**: تصدير تقرير PDF وشامل وسجلات CSV للحوادث الميدانية.

## ⚡ التشغيل والتطوير المحلي (Getting Started)

```bash
# 1. استنساخ المشروع أو الانتقال للمجلد
cd aura-operational-intelligence

# 2. تثبيت جميع المكتبات والاعتمادية
npm install

# 3. تشغيل البيئة المحلية
npm run dev

# 4. بناء نسخة الإنتاج والتأكد من سلامة الكود
npm run build
```
